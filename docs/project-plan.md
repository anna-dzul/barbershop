# План завершення барбершопу

Вимоги попереднього проєкту збережено: каталог послуг, запис клієнта,
редагування й підтверджене видалення, пошук/фільтр/сортування та прямі адреси.
Модель: id, clientName, phone, serviceId, date, time, notes, createdAt, updatedAt.
Головний сценарій: каталог → вибір → форма → підтверджений запис → деталі → редактор → список.
Джерело — mock із localStorage; сервер і реальне резервування не додаються.

| Вимога | Де перевірено |
| --- | --- |
| Вибір послуги | URL-параметр serviceId у справжньому App |
| Некоректні дані без команди | Тести validateBooking та BookingForm |
| Очікування, відмова, повтор | Компонентні та інтеграційні тести із deferred |
| Створення з переходом | Повернений сервісом server-confirmed id |
| Редагування, видалення | Справжні сторінки й провайдер з підміною сервісу |
| Збереження | Реальний mock; браузерне перезавантаження за інструкцією |
| Production | Build, HTTP preview і виконання зібраного JS у DOM |
| Підготовка захисту | README, checks, performance, defense |

Фактичні статуси та невиконані браузерні перевірки наведені у checks.md.
