# Короткий сценарій захисту

1. Пояснити потребу: клієнт вибирає послугу і залишає заявку на бажаний візит.
2. У каталозі натиснути «Записатися»: форма вже містить послугу.
3. Подати некоректну форму, показати пояснення та фокус; виправити дані.
4. Зберегти, дочекатися деталей; відредагувати побажання й показати їх у деталях.
5. Показати список, пошук без збігів і скидання; перезавантажити URL свого запису.
6. Скасувати видалення; потім підтвердити видалення тільки тестового запису.
7. Показати npm run test:run та тест, який ловить передачу службових полів.
8. Пояснити джерело → сервіс → знімок провайдера → деталі; чернетка окрема.
9. Пояснити підміни: vi.mock тільки сервіс; fetch-підміна тільки в тесті адаптера.
10. Показати preview, вимірювання чистої функції та межі висновків без мемоізації.
