# Перевірки й готовність лабораторної 4.1

## Виконаний запуск
Node 24.22.1, Vite 8.3.2, Vitest 5.1.0, jsdom 31.0.0.
Команда npm run test:run: 6 файлів, 38 тестів пройдено, помилок немає.
Логіка — 10; відбір — 2; форма — 3; інтеграція — 15; API — 5; mock — 3.
Немає довільного sleep у Vitest-тестах: керовані Promise та fake timers для mock.
У тестах всього клієнта підмінено тільки bookingService; App, маршрути, провайдер і форма справжні.
API-тести підміняють fetch, а не метод адаптера. Їхній успіх не означає підключення API.

До виправлення тести відтворили 4 дефекти: телефон із 9 цифр і пробілами,
календарну дату 2099-02-30, невідому послугу у validateBooking, відсутність фокуса.
Наступний інтеграційний тест виявив службові id і createdAt у команді update.
Після виправлень ці тести проходять. Предметні правила не розширені новими послугами
або прихованими обмеженнями часу роботи.

npm run lint завершено без помилок; 3 попередження BookingsContext.jsx:
спільний експорт компонента й хука, ініціація читання в effect, ref під час cleanup.
Попередження не приховано. Початкове читання й cleanup перевіряються тестами станів.
npm run build успішний. JS 289.56 кБ (gzip 91.31 кБ), CSS 7.24 кБ (gzip 2.33 кБ).
Зазначені розміри — вимір файлів, а не час завантаження.
Preview перевірено HTTP: /, /services, /bookings, /bookings/booking-demo-1,
/bookings/missing, /unknown повертають SPA HTML; JS і CSS доступні зі статусом 200.
Зібраний JS пройшов каталог → створення → редагування → скасування → видалення
у jsdom із реальним mock. Це доповнює HTTP, але не замінює браузер.

## Перелік готовності
| Пункт | Фактичний статус |
| --- | --- |
| Наскрізний сценарій, форми, CRUD | Перевірено компонентами, інтеграцією та зібраним JS у DOM |
| Завантаження, помилка, повтор, empty | Перевірено інтеграційними тестами |
| URL, невідома сторінка та запис | Перевірено справжнім App; HTTP fallback preview також перевірений |
| Збереження та [] | Перевірено реальним mock і localStorage |
| Структура | Фільтрація одна чиста функція, каталог не дублюється |
| Продуктивність | Виміряна чиста функція в Node; браузерний Profiler ще не виконано |
| Візуальний прохід preview й клавіатура | Виконати за README у звичайному браузері |
| Реальне зовнішнє API | Не підключалося; підготовлений адаптер перевірений із fetch-підміною |
| Конфігурація | Mock за замовчуванням, шаблон env без секретів |
| Git | Відомий репозиторій і попередній коміт; новий коміт створює користувачка |
| Docker | Базові файли підготовлені; виконання не перевірялося |
| Захист | Набір даних, сценарій і документація підготовлені |

Ручне перезавантаження URL, фільтрація, редагування й підтвердження видалення
мають бути пройдені користувачкою в production preview. Не ставте позначку
«перевірено браузером» до виконання. Дані dev та preview можуть бути різними через origin.
